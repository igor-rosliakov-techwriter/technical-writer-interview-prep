# Documentation English

## English

Short reference guides for reading and writing technical documentation and answering interview questions in English. The materials cover useful expressions, sentence patterns, and recurring mistakes from translation practice, with Russian explanations.

| Guide | Contents | When to use it |
| --- | --- | --- |
| [35 Useful Expressions](technical-english-expressions.md) | Five tables of seven expressions, with translations, examples, and usage notes. | Start here to learn phrases such as `store data`, `track changes`, and `run a command`. |
| [Common Sentence Patterns](technical-english-patterns.md) | Twelve core constructions, ready-to-use sentence models, common mistakes, and translation exercises with answers. | Use it to build sentences with `allow users to`, `before publishing`, and similar patterns. |
| [Collocations Review](technical-english-collocations-review.md) | Expressions and corrections from translation rounds 47–75, grouped by technical topic, plus grammar reminders and twenty review prompts. | Return here after practice to work on recurring mistakes and verb–noun combinations. |

Begin with the expressions, use the sentence patterns to write your own examples, and revisit the collocations review regularly. Study a small group at a time and try translating before looking at the answers.

| [Конструкции предложений](technical-english-patterns.md) | Двенадцать основных конструкций, готовые модели предложений, типичные ошибки и упражнения с ответами. | Когда нужно построить фразу с `allow users to`, `before publishing` и похожими оборотами. |
